# Demo 与回来后的验收

## 一次启动

如果旧程序仍在运行，先 Ctrl+C。然后：

```powershell
python E:\MailPhor\app.py --mode serve
```

个人页面：http://localhost:8000/index.html

独立演示：http://localhost:8000/index.html?demo=1

浏览器 Ctrl+F5 加载新样式。`serve` 本身不读取邮箱或调用AI；点击同步才会。

## 先看完整体验

1. 在个人页面确认原画像仍在；不要清理浏览器数据，不要换端口，否则看不到同一来源的localStorage。
2. 收起卡片时应能直接看到等级、理由、日期和收藏/申请状态。
3. 编辑画像兴趣后保存，观察推荐排序；同等级不一定明显变化，页面会解释。
4. 收藏、勾清单、标记已申请后刷新，操作应保留。
5. 打开Demo体验全部类别；回到个人页面，真实画像和操作不变。
6. 手机窄屏下导航与分类可以横向滑动，筛选默认折叠，卡片单列显示。

## 再验收真实同步

展开“邮箱连接与最近同步”：

- **同步一轮**：默认最多5封；会将选定正文发送至配置的AI，注意额度。
- **开启定时检查**：按POLL_SECONDS执行；保持程序与电脑运行。
- **停止定时检查**：不启动下一轮，当前批次完成后结束。

处理记录页中可把某封邮件加入下轮重新分析，入队本身不调用AI；下一次同步优先处理保存的正文节选。不会自动删除已有卡片。
