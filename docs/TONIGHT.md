# 今晚回来后，一次验收完整体验

不要先跑 `once`，先用纯网页模式看完整界面：

```powershell
python E:\MailPhor\app.py --mode serve
```

如果已有旧进程占用8000，先 Ctrl+C 停止旧进程再执行。浏览器 Ctrl+F5。

1. 个人页面：http://localhost:8000/index.html 。原画像、卡片和操作应保留。
2. Demo：http://localhost:8000/index.html?demo=1 。明确虚构样本，数据与画像独立。可以随便试，不调用AI。
3. 看卡片收起时能否读懂等级、理由、截止时间；收藏和已申请状态现在在卡片底部。
4. 编辑画像并保存，切换兴趣，观察推荐与理由；勾清单后刷新，确认进度保留。
5. 看手机或窄窗口：单列卡片，横向导航和类别，筛选默认折叠。
6. 如果愿意做真实同步，展开“邮箱连接与最近同步”，点“同步一轮”。这会调用已配置AI，默认5封。无需换CLI命令。
7. 处理记录里“加入下轮重新分析”只入队；下一次同步会优先处理保存的正文。它不能恢复旧附件或未读到的内容，不自动删旧卡片。

反馈时只需说：哪些地方不好用、哪些信息看不懂、视觉是否接近你要的Apple原生工具感觉。不需要再替开发逐项看技术日志。
